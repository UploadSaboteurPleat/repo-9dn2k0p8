# PROJECT_STATUS — ООО «САМРАУ»

Дата фиксации состояния: 2026-06-13. Живое демо: https://samrausite-wandjfwx.devinapps.com

## Краткое резюме

Одностраничный корпоративный сайт ООО «САМРАУ». Полностью реализован, наполнен
реальными фотографиями и развёрнут в виде статического сайта. Готов к передаче
и продакшен-деплою. Незавершённых обязательных задач нет; оставшиеся пункты —
улучшения (см. `TODO.md`).

## Стек и запуск

- Чистый HTML + CSS + JS, всё в одном файле `index.html`. Без фреймворков и сборки.
- Запуск: `python3 -m http.server 8090` из корня → http://localhost:8090/
  (или открыть `index.html` напрямую).
- Переменные окружения и серверная часть отсутствуют.

## Архитектурные / дизайнерские решения

- **Один файл** (`index.html`): осознанный выбор для простого статического лендинга —
  нулевые зависимости, мгновенный деплой на любой хостинг.
- **Vanilla JS** вместо фреймворков: анимации на `IntersectionObserver`, параллакс,
  sticky-blur header.
- **Слайдер «до/после»**: реализован на Pointer Events API (единая обработка мыши/тача),
  позиция управляется CSS-переменной `--pos` (0–100) и `clip-path: inset(...)` —
  без сторонних библиотек. Доступность: `role="slider"`, управление стрелками/Home/End.
- **Фирменный стиль** через CSS-переменные: зелёный `--green: #00682b`,
  яркий `--green-bright: #00d56f`, скругления `--radius: 18px`, мягкие тени.
- **Шрифты**: Inter (текст) и Manrope (заголовки) с Google Fonts.
- **Сетка проектов**: 2 карточки в ряд на десктопе/планшете, 1 — на мобильном.

## Известные проблемы / ограничения

- **Шрифты грузятся с Google Fonts по сети** — при работе без интернета шрифты
  не подгрузятся (нужно вшить локально). Не критично.
- **`logo-samrau.svg`** используется только как favicon — это упрощённая иконка,
  а не основной вордмарк (`logo-samrau-wordmark.svg`). При желании favicon можно
  заменить на брендовый.
- **Весь код в одном файле** — удобно для деплоя, но при дальнейшем росте сайта
  стоит рассмотреть вынос CSS/JS в отдельные файлы (см. `TODO.md`).
- Размеры некоторых фото 250–630 КБ — для ускорения загрузки их можно оптимизировать.
