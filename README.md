\# ООО «САМРАУ» — корпоративный сайт

&#x20;

Современный одностраничный сайт компании \*\*ООО «САМРАУ»\*\* (г. Учалы, Республика Башкортостан):

капитальный ремонт подземных буровых машин, восстановление стрел, ремонт гидроцилиндров,

изготовление узлов и комплектующих.

&#x20;

\## Стек

&#x20;

Чистый \*\*HTML + CSS + JavaScript\*\* в одном файле (`index.html`), без фреймворков и сборки.

Анимации — на vanilla JS (Intersection Observer, parallax, sticky-blur header).

&#x20;

\## Запуск

&#x20;

Откройте `index.html` в браузере или поднимите статический сервер:

&#x20;

```bash

python3 -m http.server 8090

\# затем http://localhost:8090/

```

&#x20;

\## Структура

&#x20;

\- `index.html` — вся вёрстка, стили и скрипты.

\- `images/` — изображения сайта. Сейчас это \*\*именованные плейсхолдеры\*\* (SVG);

&#x20; замените их на реальные фотографии из презентации, сохранив имена файлов.

\- `gen\_placeholders.py` — генератор плейсхолдеров (можно удалить после замены фото).

&#x20;

\## Что заменить на реальные материалы

&#x20;

\- Логотип: `images/logo-samrau.svg`.

\- Фото производства/работ: `images/\*.svg` (база, стрелы, гидроцилиндры, испытания,

&#x20; окрасочная камера).

\- Проекты «до/после»: `images/proekt-\*-do.svg` и `images/proekt-\*-posle.svg`.

&#x20;

Контактные данные (телефон, e-mail, адрес) уже заполнены по презентации.
