# ООО «САМРАУ» — корпоративный сайт

Современный одностраничный (landing) сайт компании **ООО «САМРАУ»** (г. Учалы, Республика Башкортостан):
капитальный ремонт подземных буровых машин, восстановление стрел, ремонт гидроцилиндров,
изготовление узлов и комплектующих.

Живое превью (демо): https://samrausite-wandjfwx.devinapps.com

## Стек

Чистый **HTML + CSS + JavaScript**, всё в одном файле (`index.html`). Без фреймворков,
без сборки, без зависимостей и без серверной части — это полностью статический сайт.

- Стили — внутри `<style>` в `index.html` (CSS custom properties, grid/flex, адаптив).
- Скрипты — внутри `<script>` в `index.html` (vanilla JS): анимации по `IntersectionObserver`,
  параллакс, sticky-blur header, мобильное меню, интерактивные слайдеры «до/после».
- Шрифты — Google Fonts (Inter, Manrope), подключаются по сети.

## Требования

Никаких. Для локального просмотра достаточно браузера; для корректных относительных
путей удобно поднять любой статический сервер.

Переменные окружения **не используются** (статический сайт), поэтому файла `.env` нет.

## Запуск локально

```bash
# из корня проекта
python3 -m http.server 8090
# затем открыть http://localhost:8090/
```

Либо просто открыть `index.html` двойным щелчком в браузере.

## Сборка

Сборка не требуется. Деплой = выгрузка файлов как есть.

## Деплой

Загрузите содержимое репозитория (`index.html` + папка `images/`) в корень сайта,
сохранив структуру папок. Точка входа — `index.html`.

- Обычный хостинг (cPanel/ISPmanager): в `public_html/`.
- Nginx: в `root` сайта (index.html отдаётся по умолчанию).
- Apache: в `DocumentRoot`.
- GitHub Pages / Netlify / Vercel / Cloudflare Pages: как статический сайт,
  build command не нужен, output directory — корень.
